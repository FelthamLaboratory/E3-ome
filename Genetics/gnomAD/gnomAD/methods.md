# Methods

## Inputs

The analysis uses the E3-ome gene list and gnomAD v4.1.1 constraint metrics. The E3 workbook contains gene symbol, NCBI GeneID, UniProt accession, E3 protein class, and post-publication update annotation.

The supplied E3 workbook does not contain Ensembl gene IDs. The pipeline therefore documents that primary Ensembl matching was not possible from the supplied columns and uses checked gene-symbol fallback against selected gnomAD Ensembl protein-coding rows.

## Transcript Selection

gnomAD rows are restricted to Ensembl protein-coding genes. For each Ensembl gene, the script selects:

1. MANE Select transcript where available.
2. Ensembl canonical transcript if MANE Select is unavailable.
3. A fallback transcript only if neither annotation is present.

The same procedure is applied to the E3 genes and the protein-coding background.

## Core E3 Families

Class-level analyses use 11 core E3 families: RING, degenerate RING, HECT, RBR, CRL1, CRL2, CRL3, CRL4, CRL5, Atypical and APC/C. Genes annotated to more than one family are expanded for family-level analyses and counted once in each relevant family.

## Constraint Metrics

The joined output reports LOEUF, pLI, observed and expected pLoF counts, pLoF observed/expected, missense observed/expected, missense Z-score, synonymous observed/expected, transcript-selection method, and gnomAD quality flags.

Highly loss-of-function constrained genes are defined with the gnomAD v4 recommendation:

```text
LOEUF < 0.45
```

Lower LOEUF indicates stronger depletion of predicted loss-of-function variation.

## Statistical Analyses

The script compares reliable matched E3 genes against eligible protein-coding genes with valid, unflagged LOEUF values. It reports:

- E3 genes ranked by LOEUF.
- LOEUF distribution comparison against the protein-coding background.
- Proportion of reliable matched E3 genes with `LOEUF < 0.45`, with confidence interval.
- Fisher exact test for E3 enrichment among the most constrained 15% of protein-coding genes.
- Major E3-class summaries.
- Kruskal-Wallis and Benjamini-Hochberg adjusted pairwise Wilcoxon tests for class-level LOEUF comparisons.
- Genes with strong missense constraint, using missense Z-score `>= 3.09`.
- Genes where pLoF and missense constraint provide differing signals.

Multiple class-comparison P values are corrected with Benjamini-Hochberg adjustment.

## Quality Handling

gnomAD gene and constraint flags are preserved in the output tables. Flagged or missing values are not interpreted as evidence that a gene is unconstrained and are excluded from inferential summaries.

## Reproducibility

All calculated tables, plots, and metadata are regenerated by:

```sh
Rscript Genetics/gnomAD/scripts/build_gnomad_constraint_site.R
```
